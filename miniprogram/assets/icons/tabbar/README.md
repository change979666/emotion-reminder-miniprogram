# TabBar 图标说明

## 图标要求

小程序 tabBar 图标需要满足以下要求：
- **格式**：PNG、JPG、JPEG（不支持 SVG）
- **推荐尺寸**：81px × 81px（3倍图）或 162px × 162px
- **颜色**：建议使用单色图标，未选中时使用灰色调，选中时使用主题色

## 需要的图标文件

请在此目录下放置以下图标文件：

### 个人（User）
- `user.png` - 未选中状态图标（灰色调）
- `user-active.png` - 选中状态图标（橙色 #D97706）

### 社区（Community）
- `community.png` - 未选中状态图标（灰色调）
- `community-active.png` - 选中状态图标（橙色 #D97706）

### 解忧（Help）
- `help.png` - 未选中状态图标（灰色调）
- `help-active.png` - 选中状态图标（橙色 #D97706）

## 图标设计建议

1. **个人图标**：可以使用用户头像轮廓、个人资料图标
2. **社区图标**：可以使用社区、广场、分享等图标
3. **解忧图标**：可以使用信件、对话、帮助等图标

## 图标资源

你可以从以下网站获取免费图标：
- [IconFont](https://www.iconfont.cn/)
- [Flaticon](https://www.flaticon.com/)
- [Icons8](https://icons8.com/)

下载后请转换为 PNG 格式，并调整尺寸为 81px × 81px 或 162px × 162px。


此目录用于存放小程序图标资源（如按钮、标签、状态等图标）。

建议命名规范：
- action-like.png
- action-reply.png
- status-waiting.png
- status-replied.png
